### 설비를 움직이는 소프트웨어를 만듭니다 👋

산업 현장의 제어·검사 소프트웨어를 개발합니다.<br/>
PLC와 대화하고, 카메라로 검사하고, 모션을 제어하는 데스크톱 애플리케이션이 주 무대입니다.

</div>

## 🏭 하는 일

- **설비 제어 HMI** — WPF · Avalonia 기반 데스크톱 애플리케이션 설계/개발
- **PLC · 모션 제어 통신** — Mitsubishi MC 프로토콜, Modbus/TCP 실시간 폴링
- **머신 비전 검사** — Cognex VisionPro 기반 검사 시스템
- **설비 시뮬레이션** — Unity 기반 장비 시뮬레이터
